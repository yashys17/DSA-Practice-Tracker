# 🚀 DSA Practice Tracker

A modern full-stack web application built to track Data Structures and Algorithms (DSA) practice efficiently.

This project helps students and programmers monitor their coding progress, maintain consistency, analyze performance, and keep important notes for every problem they solve.

---

## ✨ Features

### 📊 Dashboard Analytics
- Total Problems Counter
- Easy / Medium / Hard Distribution
- Progress Percentage
- Coding Streak Tracker
- Interactive Charts

### 📝 Problem Management
- Track DSA Problems
- Solved / Pending / Unsolved Status
- Date Solved Tracking
- Problem Links
- Search Functionality
- Filter by Difficulty & Platform

### 📚 Learning Notes
- Detailed Notes for Every Problem
- Pseudocode
- Time Complexity
- Space Complexity
- Key Learning Points

### 🎨 User Experience
- Clean Modern UI
- Dark Mode Support
- Responsive Design
- Topic-wise Analytics Chart

### 📄 Reports
- Export Progress Report

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yashys17/DSA-Practice-Tracker.git
```

### 2️⃣ Open Project

```bash
cd DSA-Practice-Tracker
```

### 3️⃣ Install Dependencies

```bash
pip install flask flask-cors
```

### 4️⃣ Run Backend

```bash
cd Backend
python app.py
```

### 5️⃣ Open Frontend

Open:

```text
Frontend/index.html
```

in your browser.

---

## 🎯 Why This Project?

Preparing for coding interviews and placements often becomes difficult when tracking hundreds of solved problems manually.

This project was created to:

- Track coding consistency
- Maintain structured notes
- Monitor learning progress
- Visualize strengths and weaknesses
- Build a better DSA preparation workflow
